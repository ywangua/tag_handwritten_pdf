# Tag Handwritten PDF

A quick and dirty workaround to **trick** Blackboard's Accessibility Checks.

**Warning**: do not use this program if you want real accessibility; instead, build from LaTeX/Typst/Word/Powerpoint sources to generate accessible PDF files.

* Written in Python (https://www.python.org/)
* Helper programs: magick (https://imagemagick.org/) and typst (https://typst.app/). Credits go to the corresponding authors for these programs.
* Tested under Linux (Debian/Ubuntu) and WSL
